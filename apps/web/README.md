# Web

Frontend for Word Wizards.

## Local Development

1. Copy the `.env.example` file to `.env.local`.
2. Have supabase running, see the root readme for more info.
3. Go to `127.0.0.1:54323`
4. Click *Connect* button in the top left corner.
   ![Connect button.](https://i.imgur.com/zN9Rnah.png)
5. Grab the env values for a Next.js app.
   ![env values for Next.js.](https://i.imgur.com/BodL96w.png)
6. Follow the instructions in the root readme to start the app.
